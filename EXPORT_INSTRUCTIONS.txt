QUICK EXPORT GUIDE
==================

IMPORTANT: You need to install Web Export Templates first!

STEP 0: Install Web Templates (if you haven't)
- In Godot: Editor → Editor Layout → ... (top menu)
- Look for: Editor → Preferences (or Tools → Export)
- Find: "Export" section
- Click: "Import/Reimport" next to Web templates
- OR download from: https://godotengine.org/download/
- Select "Web Export Templates"

STEP 1: Open Godot
- Open C:\Users\frost\OneDrive\Documents\meka-game in Godot 4.6

STEP 2: Export
- Click: Project → Export
- If no "Web" preset: Click "Add Preset" → select "Web"
- Export path: build/web/index.html (or choose meka-game-web folder)
- Click: "Export All" button (bottom right)

STEP 3: Files Generated
Export creates:
  * mekagame.js
  * mekagame.wasm
  * mekagame.pck
  * index.html (updated)

STEP 4: Copy to Web Folder
- Copy those 4 files to: meka-game-web/

STEP 5: Push to GitHub
- Create a new repo called "meka-game"
- Create a branch called "gh-pages"
- Push all files from meka-game-web/ to gh-pages

STEP 6: Enable GitHub Pages
- Go to repo Settings → Pages
- Source: gh-pages branch
- Save

Your game will be live at: https://YOUR-USERNAME.github.io/meka-game

THAT'S IT!

---

TROUBLESHOOTING:
If you still see no "Web" option:
1. Make sure you're using Godot 4.6
2. Go to Editor → About to verify version
3. If templates missing, download from godotengine.org
