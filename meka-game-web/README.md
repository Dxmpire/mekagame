# MekaGame Web Export

This folder contains the web version of MekaGame ready to upload to GitHub Pages.

## What's Here

- `index.html` - Entry point for the web game
- `mekagame.js` - Godot engine runtime (generated by export)
- `mekagame.wasm` - Godot engine WebAssembly (generated by export)
- `mekagame.pck` - Game data and resources (generated by export)

## How to Generate the Export Files

The `.js`, `.wasm`, and `.pck` files need to be generated by Godot:

1. Open the MekaGame project in Godot 4.6
2. Go to **Project → Export**
3. Click **"Add Preset"** → Select **"Web"**
4. Set export path to: `build/web/index.html`
5. Click **"Export All"**

This will create:
- `mekagame.js`
- `mekagame.wasm`
- `mekagame.pck`
- And update `index.html`

## Upload to GitHub Pages

1. Copy all files from this folder
2. Push to your GitHub repo (either to `gh-pages` branch or `/docs` folder on main)
3. Enable GitHub Pages in repo settings
4. Your game will be live at: `https://your-username.github.io/meka-game`

## Important Notes

- Save/load system uses browser storage (IndexedDB) instead of local disk
- CORS is not an issue with GitHub Pages
- The game will work on desktop and mobile browsers
- Performance should be good on modern browsers

## Troubleshooting

If the game won't load:
- Check browser console (F12) for errors
- Verify all `.js`, `.wasm`, and `.pck` files are present
- Make sure the HTML file is named `index.html`
